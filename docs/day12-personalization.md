# День 12: персонализация ассистента

Реализован явный слой **персоны ассистента** поверх модели памяти (День 11).

## Что добавлено

| Компонент | Описание |
|-----------|----------|
| **AssistantProfile** | Профиль персоны: имя, стиль, формат, ограничения, описание роли |
| **4 встроенных персонажа** | Годжо Сатору, Джайна Проаудмур, Тарья Турунен, Роберт Мартин — с аватарками |
| **Кастомные профили** | Настройки → CRUD своих персон |
| **ProfilePromptBuilder** | Блок `--- ПЕРСОНА АССИСТЕНТА ---` в system prompt **каждого** запроса |
| **ProfileAvatar** | Аватар в чате, при выборе профиля, в списке тем |

## Персона vs память (День 11)

```
[базовый промпт]
--- ПЕРСОНА АССИСТЕНТА ---       ← День 12 (все стратегии)
--- РАБОЧАЯ ПАМЯТЬ ---            ← День 11 (MEMORY_LAYERS)
--- ДОЛГОВРЕМЕННАЯ ПАМЯТЬ ---      ← День 11 (MEMORY_LAYERS)
[messages: short-term window]
```

- **Персона** — *как* отвечает ассистент (стиль, роль)
- **Память** — *что* помнит о пользователе и задаче

## Как проверить

### 1. A/B-тест персонажей

1. «Новая тема» → выберите **Годжо Сатору** → «Начать диалог»
2. Спросите: «Посоветуй аниме на вечер»
3. Новый диалог с **Робертом Мартином**, тот же вопрос про REST/coroutines
4. Сравните: **текст** (тон, формат) и **UI** (аватар + имя над ответом)

| Персона | Вопрос | Ожидание |
|---------|--------|----------|
| Годжо | «Посоветуй аниме» | Разговорный тон, отсылки к жанрам |
| Джайна | «Как спланировать релиз?» | Пошаговый план, «стратегический» тон |
| Тарья | «Что такое minor scale?» | Образное, эмоциональное объяснение |
| Uncle Bob | «Объясни coroutines» | SOLID, чистый код, без воды |

### 2. Автоматический учёт профиля

1. Выберите персону при создании чата
2. Задайте любой вопрос **без** напоминания о стиле
3. Ответ должен соответствовать персоне — профиль уже в system prompt

### 3. Кастомный профиль

1. Home → ⚙ Настройки → «+» 
2. Имя: «Kotlin Mentor», ограничения: «только Kotlin Multiplatform»
3. Новый диалог с этим профилем → технический вопрос
4. Ответ в контексте KMP, дефолтный аватар

### 4. С Memory Layers

1. Персона «Учитель» + Memory Layers
2. Сессия 1: «Бюджет MVP 2 млн» → working memory
3. Сессия 2 (новый чат, та же персона): стиль от персоны + факты из longTerm
