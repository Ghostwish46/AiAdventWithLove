# День 10: стратегия FACTS_KV (sticky facts)

## Поведение

- На экране и в сохранённом диалоге — **полная лента** сообщений.
- Перед каждым ответом на сообщение пользователя вызывается **отдельный нестриминговый** запрос: модель получает текущие факты (JSON), последние реплики и новый текст пользователя и возвращает **только JSON** `string → string`.
- В **основной** запрос (стрим) уходит: системный промпт + блок **«Зафиксированные факты…»** + **последние N** реплик (`SimpleAgent.KEEP_LAST_MESSAGES`), как у SLIDING_WINDOW.
- При ошибке парсинга или API при слиянии фактов **сохраняются предыдущие** факты; стрим всё равно выполняется.

## Персистентность

- В `Conversation` поле `stickyFactsJson` (Gson), вместе с `contextStrategy = FACTS_KV`.

## UI

- Чип **«Факты»** в шапке чата; в сводке диалога — краткий превью фактов (до 500 символов).

## Затраты

- На каждое пользовательское сообщение в режиме FACTS_KV добавляется **ещё один** запрос к API (слияние фактов).
