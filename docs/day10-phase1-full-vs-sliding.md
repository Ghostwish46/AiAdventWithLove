# День 10, фаза 1: сравнение FULL и SLIDING_WINDOW

## Что в приложении

- **Полная** — в запрос к модели уходит вся история чата (как на экране).
- **Окно N** — в запрос уходит только последние N сообщений (роль user/assistant по очереди); на экране и в сохранённом диалоге по-прежнему полная лента.

N задаётся константой `SimpleAgent.KEEP_LAST_MESSAGES` (сейчас 8).

## Таблица сравнения (заполни вручную)

| Критерий | FULL | SLIDING_WINDOW |
|----------|------|----------------|
| Качество ответов (11–13) | | |
| Стабильность деталей (не путает ли ранние пункты) | | |
| Prompt tokens последнего запроса (из сводки в чате) | | |
| Удобство (понятность режима) | | |

## Ожидаемое поведение

- При **SLIDING** после длинного диалога модель может «забыть» начало — это ожидаемо; сводка показывает «≈ при FULL было бы» и оценку экономии токенов.
- При **FULL** расход токенов растёт с длиной диалога; зато контекст целый.
